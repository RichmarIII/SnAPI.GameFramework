# SnAPI.GameFramework Docs

This directory holds durable project context used by humans and AI agents.

- `ARCHITECTURE.md` is the architecture entry point and context router.
- `architecture/` holds focused architecture documents for runtime/core, asset
  pipeline, editor/UI, renderer integration, Conduit/scripting, project/build
  packaging, build flags/dependencies, testing/diagnostics, API sketches, and
  roadmap context.
- `CODING_STYLE.md` defines source layout, file granularity, naming, helper
  placement, and include-boundary rules.
- `CODE_DOCUMENTATION.md` defines public API documentation, tutorials, and
  generated-doc expectations.
- `WORKFLOW.md` defines the mandatory plan, branch, merge, and completion flow
  for code and feature work.
- `VALIDATION.md` lists canonical local build, test, editor, and docs checks.
- `TECH_DEBT.md` tracks cleanup too small or too undefined for a full execution
  plan.
- `exec-plans/active/` holds plans that are currently being implemented,
  blocked, or still need review.
- `exec-plans/completed/` holds completed, archived, or obsolete plans.
- `exec-plans/TEMPLATE.md` is the starting point for new active plans.
- `site/` is generated MkDocs output. Do not edit it by hand.
