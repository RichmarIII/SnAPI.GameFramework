# Execution Plans

Execution plans are the durable work units for code and feature changes.

- `active/` contains plans that are currently being implemented, blocked, or
  still need review.
- `completed/` contains plans that were completed, merged, archived, or closed
  as obsolete.
- `TEMPLATE.md` is the starting point for new plans.

Do not use chat history as the only source of truth for long-running work. Update
the active plan as facts change.
