    SnAPI::GameFramework::TSubClassOf¶

    Reflected handle that stores a subclass selection constrained to a reflected base type.

    TSubClassOf<TBase> is the type-selection counterpart to TAssetRef: instead of pointing to an asset instance, it points to reflected type metadata that must satisfy TypeRegistry::IsA(Type, TBase).

    Core semantics: - The stored TypeId is authoritative when valid. - TypeName is a fallback/display string and is refreshed from TypeRegistry when a valid type is set. - SetTypeByName() matches either the fully qualified reflected name or the final ::ShortName. - EnumerateTypes() includes the base type itself and every currently registered derived type.

    Threading model: - Value operations are thread-safe in isolation. - Validity and enumeration depend on the global TypeRegistry.
